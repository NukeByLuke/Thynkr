Please place your logo images in this directory:

1. logo.png - The main logo icon (used in the app header and sidebar)
2. favicon.png - The browser tab icon

If you have separate dark/light mode versions, you can name them:
- logo-dark.png (for dark mode)
- logo-light.png (for light mode)

And update the Logo.tsx component to switch between them.
For now, the code is configured to use 'logo.png'.
