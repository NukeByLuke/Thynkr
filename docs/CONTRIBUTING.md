# 🧠 Contributing to Thynkr

Welcome! This guide is designed to be **visual, simple, and easy to read**. We use a color-coded system to manage everything directly on GitHub.

---

## 🚦 Can I Merge This?

Look at the **Labels** on the Pull Request.

| Label                                                                                         | Meaning                                 | Can I Merge?   |
| :-------------------------------------------------------------------------------------------- | :-------------------------------------- | :------------- |
| ![SAFE TO MERGE](https://img.shields.io/badge/SAFE%20TO%20MERGE-238636?style=for-the-badge)   | **All Clear!** Automated checks passed. | **✅ YES**     |
| ![MANUAL REVIEW](https://img.shields.io/badge/MANUAL%20REVIEW-d29922?style=for-the-badge)     | Needs a human to look at it first.      | **⚠️ WAIT**    |
| ![DO NOT MERGE](https://img.shields.io/badge/DO%20NOT%20MERGE-000000?style=for-the-badge)     | Work in progress or blocked.            | **❌ NO**      |
| ![BREAKING CHANGE](https://img.shields.io/badge/BREAKING%20CHANGE-b60205?style=for-the-badge) | Dangerous! Changes how things work.     | **🛑 CAREFUL** |

> **Rule:** Even if the automated checks (the little circles) are failing, check the label. If it says **SAFE TO MERGE**, you are good. If not, wait.

## ✅ How to Contribute (The Easy Way)

You don't need to run code on your computer if you don't want to. You can do almost everything on GitHub!

### 1. View Reports

Go to the **"Issues"** tab on GitHub. Look for things labeled ![Bug](https://img.shields.io/badge/bug-faad14).

### 2. Edit Files

1. Go to the **"Code"** tab.
2. Find the file you want to change.
3. Click the pencil icon (✏️) to edit.
4. Make your changes.

### 3. Save Changes (Limit the Noise)

1. Scroll to the bottom "Commit changes" box.
2. Select **"Create a new branch for this commit and start a pull request"**.
3. Click the green button **"Propose changes"**.

### 4. Checklist for Merging

When you look at a Pull Request (PR):

- [ ] Is it labeled correctly? (Add a colored label!)
- [ ] Does it have the ![SAFE TO MERGE](https://img.shields.io/badge/SAFE%20TO%20MERGE-238636) label?
- [ ] **Click the Big Green Button!**

## 🧠 Memory Aids

- **Green** = GO / Good / New Features
- **Red** = STOP / Security / Danger
- **Blue/Purple** = Tech Stuff (System/Config)
- **Yellow/Orange** = Warning / Bugs / Needs Review
- **Black** = STOP / Blocked

That's it! Keep it colorful and clear. 🌈
